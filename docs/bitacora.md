# Bitácora de programación con IA
todos los promts usados :P
Promt#1
Se necesita crear la siguiente estructura de carpetas para un proyecto que usara una apikey (TheCatAPI)
La carpeta principal del proyecto se llama Tarea2. Dentro de ella hay una carpeta llamada public que contiene el archivo index.html, una carpeta css con el archivo styles.css, una carpeta js con el archivo app.js y una carpeta img para las imágenes. También dentro de Tarea2 hay una carpeta llamada docs que contiene el archivo bitacora.md. Además, en la raíz de Tarea2 están los archivos server.js, .env, .env.example, .gitignore, package.json y README.md. 
Pront #2
Para el formato de la página.
Para el encabezado usa #170E2C para el color , dentro tendra que tener el titulo “Simplemente Gato” de color blanco puro en letras pixel
Para el cuerpo de la página usa el color #5B1F61 y en forma de patrón agregar gatos pixel art minimalistas, en medio de todo un recuadro en donde aparezca la imágenes de los gatos que serán enviados, abajo de ese recuadro poner un botón para generar otra imagen.
Todo esto con una estética pixel retro 
Promt #3

Pront #4
Crea un apartado antes de ver a los gatos ,en esta aparecerán las razas de gatos con una descripción de estos ,para luego aparecer el botón de generar gato y poder ver a los gatos que se generan
Promt #5
